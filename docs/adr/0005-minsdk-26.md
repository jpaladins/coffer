# ADR 0005 — minSdk 26 (Android 8.0)

**Stato:** accettato (2026-11-04)

## Contesto
"Apri con un'altra app" senza file temporanei in chiaro richiede `StorageManager.openProxyFileDescriptor`, disponibile da API 26.

## Decisione
minSdk = 26. targetSdk = l'ultima API richiesta dal Play Store.

## Conseguenze
Restano esclusi i dispositivi con Android 7.x e precedenti, che sono una quota marginale.
